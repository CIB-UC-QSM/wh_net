# Experiments

These scripts preserve research analyses that are outside the maintained regression suite.

- `evaluation/`: COSMOS, Sim2, Graz, and in-vivo evaluation workflows.
- `diagnostics/`: focused numerical investigations.
- `legacy/`: prior training pipeline and an untouched source backup.
- `julia/`: Julia environment used by external QSM evaluation steps.

Run scripts from the repository environment with `uv run python experiments/<path>.py`. Paths are resolved through `whnet.paths`.
